## Permanganate ($\text{MnO}_4^-$) — Neutral / Faintly Alkaline Medium

> **Core Half-Reaction:**
> $\text{MnO}_4^- + 2\text{H}_2\text{O} + 3e^- \rightarrow \text{MnO}_2 + 4\text{OH}^-$
> * Oxidation State Change: $\text{Mn}(+7) \rightarrow \text{Mn}(+4)$
> * Visual Change: Purple solution $\rightarrow$ Dark brown precipitate ($\text{MnO}_2$)

### The 3 Essential NCERT Reactions

1. **Iodide to Iodate**
   $$2\text{MnO}_4^- + \text{H}_2\text{O} + \text{I}^- \rightarrow 2\text{MnO}_2 + 2\text{OH}^- + \text{IO}_3^-$$
   * $\text{I}^- (-1) \rightarrow \text{IO}_3^- (+5)$

2. **Thiosulfate to Sulfate**
   $$8\text{MnO}_4^- + 3\text{S}_2\text{O}_3^{2-} + \text{H}_2\text{O} \rightarrow 8\text{MnO}_2 + 6\text{SO}_4^{2-} + 2\text{OH}^-$$
   * $\text{S}_2\text{O}_3^{2-} (+2) \rightarrow \text{SO}_4^{2-} (+6)$

3. **Manganese(II) Salt to Manganese Dioxide (Comproportionation)**
   $$2\text{MnO}_4^- + 3\text{Mn}^{2+} + 2\text{H}_2\text{O} \rightarrow 5\text{MnO}_2 + 4\text{H}^+$$
   * $\text{Mn}(+7) + \text{Mn}(+2) \rightarrow \text{Mn}(+4)$

## Chromate–Dichromate Interconversion (pH Dependent)

> **Equilibrium Equation:**
> $$2\text{CrO}_4^{2-} + 2\text{H}^+ \rightleftharpoons \text{Cr}_2\text{O}_7^{2-} + \text{H}_2\text{O}$$

* **Acidic Medium ($\text{pH} < 7$):**
  * Shift: **Forward** (Adding $\text{H}^+$ drives equilibrium to the right)
  * Species: Dichromate ion ($\text{Cr}_2\text{O}_7^{2-}$)
  * Color: **Orange**
  * Oxidation State: $+6$

* **Basic Medium ($\text{pH} > 7$):**
  * Shift: **Backward** (Adding $\text{OH}^-$ removes $\text{H}^+$)
  * Reaction: $\text{Cr}_2\text{O}_7^{2-} + 2\text{OH}^- \rightarrow 2\text{CrO}_4^{2-} + \text{H}_2\text{O}$
  * Species: Chromate ion ($\text{CrO}_4^{2-}$)
  * Color: **Yellow**
  * Oxidation State: $+6$

* **Key Concept:** This is a **pH-dependent interconversion**, NOT a redox reaction. Oxidation state of Chromium remains $+6$ in both forms.
