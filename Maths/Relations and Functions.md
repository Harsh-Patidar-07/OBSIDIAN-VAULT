# Log Questions

Given,

$$
\log_{0.5}\left(\frac{5-2x}{x}\right)\ge0
$$

### Rule: Log Inequalities : Log with base **smaller than 1**

For

$$
\log_a(t)\ge0
$$

- If $a>1$, then

  $$
  t\ge1
  $$

- If $0<a<1$, then

  $$
  0<t\le1
  $$

**Reason:** When $a>1$, the logarithmic function is increasing, so the inequality is preserved. When $0<a<1$, it is decreasing, so the inequality reverses.
