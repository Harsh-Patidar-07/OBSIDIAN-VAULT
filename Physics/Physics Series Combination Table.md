### Series Combination Equivalence

|**Resistor-like Behavior (Xeq​=X1​+X2​)**|**Capacitor-like Behavior (Xeq​1​=X1​1​+X2​1​)**|
|---|---|
|**Resistors ($R$)**<br><br>  <br><br>$\bullet$ $R_{\text{eq}} = R_1 + R_2$<br><br>  <br><br>$\bullet$ Law: $V = IR$ (Potential drops add up: $V = V_1 + V_2$)|**Capacitors ($C$)**<br><br>  <br><br>$\bullet$ $\frac{1}{C_{\text{eq}}} = \frac{1}{C_1} + \frac{1}{C_2}$<br><br>  <br><br>$\bullet$ Law: $V = \frac{Q}{C}$ (Charge $Q$ is identical; $V$ adds up)|
|**Inductors ($L$)** (No mutual inductance)<br><br>  <br><br>$\bullet$ $L_{\text{eq}} = L_1 + L_2$<br><br>  <br><br>$\bullet$ Law: $V = L \frac{dI}{dt}$ (Same $\frac{dI}{dt}$, emfs add up)|**Springs ($k$)** (Spring Constant)<br><br>  <br><br>$\bullet$ $\frac{1}{k_{\text{eq}}} = \frac{1}{k_1} + \frac{1}{k_2}$<br><br>  <br><br>$\bullet$ Law: Tension $F$ is uniform; extensions add up: $x = x_1 + x_2$|
|**Thermal Resistance ($R_{\text{th}}$)**<br><br>  <br><br>$\bullet$ $R_{\text{th, eq}} = R_{\text{th1}} + R_{\text{th2}}$<br><br>  <br><br>$\bullet$ Law: Heat current $H$ is constant; temperature drops add up|**Thermal Conductance ($K_{\text{th}}$)**<br><br>  <br><br>$\bullet$ $\frac{1}{K_{\text{th, eq}}} = \frac{1}{K_{\text{th1}}} + \frac{1}{K_{\text{th2}}}$<br><br>  <br><br>$\bullet$ Conductance is the exact inverse of resistance ($K_{\text{th}} = \frac{1}{R_{\text{th}}}$)|
|**Fluid Resistance to Laminar Flow ($R_f$)**<br><br>  <br><br>$\bullet$ $R_{f,\text{eq}} = R_{f1} + R_{f2}$<br><br>  <br><br>$\bullet$ Poiseuille's law: $\Delta P = Q R_f$ (Pressure heads add up for same flow rate $Q$)|**Electrical Conductance ($G$)**<br><br>  <br><br>$\bullet$ $\frac{1}{G_{\text{eq}}} = \frac{1}{G_1} + \frac{1}{G_2}$<br><br>  <br><br>$\bullet$ Where $G = \frac{1}{R}$|
|**Spring Compliance / Flexibility ($S = \frac{1}{k}$)**<br><br>  <br><br>$\bullet$ $S_{\text{eq}} = S_1 + S_2$<br><br>  <br><br>$\bullet$ Extension per unit force adds directly in series|**Elastic Rods / Wires ($K = \frac{YA}{L}$)**<br><br>  <br><br>$\bullet$ $\frac{1}{K_{\text{eq}}} = \frac{1}{K_1} + \frac{1}{K_2}$<br><br>  <br><br>$\bullet$ Rods end-to-end behave identically to springs in series|
|**Torsional Spring Compliance ($1/C_{\theta}$)**<br><br>  <br><br>$\bullet$ Angular twist per unit torque adds up: $\theta = \theta_1 + \theta_2$|**Torsional Springs ($C_{\theta}$ or $k_t$)**<br><br>  <br><br>$\bullet$ $\frac{1}{C_{\theta,\text{eq}}} = \frac{1}{C_{\theta,1}} + \frac{1}{C_{\theta,2}}$<br><br>  <br><br>$\bullet$ Restoring torque $\tau$ is uniform along shafts in series|
