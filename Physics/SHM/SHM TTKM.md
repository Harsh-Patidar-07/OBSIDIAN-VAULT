- **First Principles & Intuition:** Phase is the total argument of the sinusoidal function at a specific instant. The phase difference is simply the absolute difference between these two arguments.
    
- **Calculation:**
    
    At $t = 0.5\text{ s}$:
    
    $$\phi_1 = 10\pi(0.5) + \frac{\pi}{3} = 5\pi + \frac{\pi}{3} = 5(180^\circ) + 60^\circ = 960^\circ$$
    
    $$\phi_2 = 8\pi(0.5) + \frac{\pi}{4} = 4\pi + \frac{\pi}{4} = 4(180^\circ) + 45^\circ = 765^\circ$$
    
    $$\Delta\phi = \phi_1 - \phi_2 = 960^\circ - 765^\circ = 195^\circ$$
    
- **Correct Option:** **(A)**

## The one formula worth remembering

For two SHMs having the same amplitude and same angular frequency:

$$\boxed{d_{\max}=2A\sin\frac{\phi}{2}}$$

This is a standard result worth keeping in your BITSAT formula notes.
